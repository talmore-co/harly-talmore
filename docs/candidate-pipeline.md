# Candidate profiles, referrals and pipelines

Trashing a job removes it from active pipelines but preserves its candidates.
Users with workspace-wide candidate access can still open those profiles.
Assigned-job roles still need access through a current, accessible job.
Trashed candidates and candidates in other workspaces remain inaccessible.

Use **Add to pipeline** on a candidate profile to create an application directly,
without adding the person to the talent pool first. Choose an open job and confirm.
The application starts in that job's first stage. Existing applications are not
reopened or duplicated.

When a candidate has a referral for the selected job, the application source is
**Referral**. The referral record, referrer and notes remain intact. Otherwise,
the source is **Manual**. The dialog suggests an eligible referred job first and
shows the source before confirmation. The server determines the source from the
stored referral records.

Adding a referral alone still records a recommendation. It does not automatically
create an application. After saving a referral, use **Add to pipeline** to proceed.

Adding to a pipeline requires candidate-edit permission for both the candidate
and the target job. This action does not send an application receipt or interview
invitation email.

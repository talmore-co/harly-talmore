# Staff navigation

Desktop navigation opens expanded, with a collapse button. A per-user browser
cookie remembers the preference for one year and the server renders that choice
on the next visit. Short screens scroll the main links while Settings and Your
account stay at the bottom. Mobile uses the same destinations in a drawer.

- Home
- Work: Inbox, Tasks, Calendar
- Recruiting: Pipeline, Candidates, Jobs, Clients
- Documents, Reports
- Settings, Your account

Candidates contains All candidates, Talent pool and Trash links. Talent pool
keeps its existing URL and highlights Candidates in the sidebar.

Settings contains Career page, Templates, Team & access and Documents alongside
the existing configuration sections. Career page opens the existing fullscreen
editor. Team & access links to the colleague directory. Document settings manage
categories and link to existing retention/privacy and signature settings when
permitted. Operational documents remain in the main sidebar.

Each settings section retains its own permission. Opening Settings routes users
without company-settings access to a section they can use, including users with
only template-management access. Existing template-list bookmarks redirect to
Settings; template editing keeps the existing fullscreen editor.

There is no global document-requirements configuration in the current app.

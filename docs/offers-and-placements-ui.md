# Offers and placements

The candidate's Offers & hire tab displays one list for the current application.
Rows identify client offers, offers prepared/sent through Talmore, and the
application's recorded placement. The list includes dates, details, statuses and
a View action. Empty applications show a small text message, without inline
forms or separate empty-state cards.

Create offer opens a dialog. Client offers are internal records and require a
linked client. Choosing an offer to send through Talmore opens the existing offer
editor as a dialog; saving creates a draft and sending remains explicit.
Existing Talmore offers retain their send, decision, withdrawal and signature
actions in the detail view.

Create placement opens the hire date and optional terms dialog. Saving marks the
application as hired; no offer is required. An existing placement is edited from
its row rather than creating a duplicate. The screen uses the existing hire
fields and does not introduce a new placement table or migration.

All records follow the application selection shared with candidate actions.

The list fills the tab width. Search matches type, status, client, date, title
and recorded terms/notes. Type, status and client filters combine with search;
Clear filters resets them. Counts show visible and total records.
Client offers retain their recorded client; placements and Talmore offers show
the current job-client assignment.
